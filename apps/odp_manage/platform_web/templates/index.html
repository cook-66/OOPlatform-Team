从数据到决策的水下视觉闭环平台

ODPlatform 面向水下目标识别场景，打通「数据治理 → 模型训练 → 在线推理 → 多模态语义解释 → 成本度量」全链路。底层由 YOLO11s 完成高精度目标检测， 上层由 DeepSeek 大模型生成可读的水下场景分析，Django 提供推理与计费服务， Vue 3 + ECharts 构建可视化控制台，形成可审计、可度量、可扩展的 AI 闭环。
